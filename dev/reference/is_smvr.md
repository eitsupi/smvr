# Check if an object is a `smvr` object

Check if an object is a `smvr` object

## Usage

``` r
is_smvr(x)
```

## Arguments

- x:

  An object.

## Value

Indicates whether `x` is a
[smvr](https://eitsupi.github.io/smvr/dev/reference/smvr.md) object.

## Examples

``` r
is_smvr(smvr(1, 2, 3))
#> [1] TRUE
```
